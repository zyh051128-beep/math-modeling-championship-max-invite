安装到 Codex

  1. 完整解压 ZIP，进入含有《安装说明》的 maxx-share 目录。
  2. 用已安装 Codex CLI 的 PowerShell 或终端在此目录执行 
    codex plugin marketplace add .
codex plugin add math-modeling-championship-max@maxx-share
codex plugin list --marketplace maxx-share
  3. 看到插件已启用后，重新打开 Codex，在新对话输入 $math-modeling-championship-maxx。
